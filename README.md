# HR Management System

A Human Resource Management System built with Laravel 12, Inertia.js, Vue 3, and Tailwind CSS.

## 🚀 Tech Stack

- Laravel 12
- PHP
- Inertia.js
- Vue 3
- Tailwind CSS
- Vite
- SQLite / MySQL
- Spatie Laravel Permission

## 📌 Features

### User Management
- User list
- Create user
- Edit user
- Delete user
- Role assignment
- Password management

### Authentication
- Login
- Logout
- Authentication and authorization

### Role & Permission
- Role management
- Permission management
- Role-based access control

### Employee Management
- Employee list
- Employee profile
- Employee creation
- Employee update
- Department assignment
- Position assignment
- Branch assignment
- Employment status

### Organization
- Department management
- Position management
- Branch management

### Attendance
- Clock in
- Clock out
- Attendance history
- Late calculation
- Shift assignment

### Overtime
- Overtime request
- Overtime approval
- Overtime tracking

### Leave Management
- Leave types
- Leave balance
- Leave request
- Leave approval
- Leave balance validation

## 🗄️ Database

The system includes relationships between:

- Users
- Employees
- Departments
- Positions
- Branches
- Shifts
- Shift Assignments
- Attendances
- Overtime
- Leave Types
- Leave Balances
- Leave Requests
- Roles
- Permissions

## 🏗️ Architecture

This project uses:

- Service Layer
- Form Request Validation
- Eloquent ORM
- Eloquent Relationships
- Inertia.js
- Vue 3
- Role-based authorization
